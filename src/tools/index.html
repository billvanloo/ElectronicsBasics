How these tools work

  • Moving dots show conventional current (+ to −). Every dot is the same amount of charge and moves at the same speed, so closer dots mean more current.
  • Wire colors show voltage: warm colors for higher voltage, cool colors for lower. Values are always labeled too.
  • Most tools ask for a prediction before showing the answer.
  • Everything works by keyboard, has captions or text descriptions, and respects the “reduce motion” setting.
  • No accounts, no tracking, and nothing leaves the page. Each tool is a single HTML file.
